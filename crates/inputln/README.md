# Read User Input Line

Reads user input line from the console.

> See more macros: [docs](https://docs.rs/macron), [repository](https://github.com/fuderis/macron-rs).

## Examples:

```rust
let input = inputln!("Enter word 'Test': ");
assert_eq!(input, "Test");
```
